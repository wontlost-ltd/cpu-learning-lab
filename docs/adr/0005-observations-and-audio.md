# ADR 0005：有界观察流与用户教学音频分类

## 状态与交付范围

P4 的离线原型已实现，真实采集与能耗验收未完成。核心是 C++20 标准库，没有预训练模型、GPU、语音 API 或领域标签表。新音频学习器与 P3 算术技能库并列；声音分类没有伪装成通过 P3 验收的可执行算术技能。

## 观察契约与时钟

`Observation` 保存来源、严格递增的传输序号、采集点时间戳（毫秒）、调用者提供的时钟偏移与误差上界、10 维音频特征。当前只支持音频特征，不宣称已有通用多模态契约。时间指采集块起点，未建模完整持续区间；无自动时钟同步。

对齐时间 = 原始时间 + 偏移。两点只有在 `abs(t1-t2)+error1+error2 <= tolerance` 时才被列为可对齐，表示误差范围内的最坏时间差仍合格。返回所有合格配对，不代表因果、不限定一对一、不表示整段音频同步。单次最多输出 4096 对，超出则明确报错。

默认队列 64 条（可配置 1..4096）、16 个来源；同一来源容忍 1000 ms 的时间乱序（可配置 0..60000），但序号必须增加。按校正时间排序。重复／重排序号、过迟、来源数超限和缓冲满都有明确状态。满时拒绝新事件，调用方读取最早事件后可重试原序号，不静默驱逐。排空后仍保留来源水位，以拒绝重传；来源表没有自动重置或新设备会话协议。

当前是同步单线程、进程内缓冲，CLI `observe` 演示按块输入；没有后台采集线程、硬件权限、断线存储或跨设备可靠传输。实时摄像、音频流调度和手机适配属于后续阶段。

## 音频适配器与先验

RIFF/WAVE，单声道 PCM16，小端，采样率 8..48 kHz，长度 50 ms..2 s，文件最多 2 MB；拒绝截断、不一致 RIFF 长度、重复 fmt/data、奇数 PCM 长度及不支持的格式。块布局允许未知扩展块及标准偶数字节 padding。不自动重采样。

10 维特征 = RMS、过零率、125/250/500/1000/2000/3000/4000/6000 Hz 的八个 Goertzel 探针归一化能量。先计算 Hann 窗，再复用给各探针；超过奈奎斯特频率的探针禁用。它们是人工选定的信号处理先验，**不是学会的语义编码器**。探针不是完整频带覆盖，对探针间的真实声音、背景噪声、不同设备与房间声学可能失效。

## 在线教学、未知与纠错

最多 256 条带用户标签的样本，ID 和标签各最多 64 字节。最近邻按标签取最小特征距离；RMS 权重 0.25，其他维权重 1；距离大于 0.30 或前两标签距离差小于 0.03 时返回未知。这些固定阈值没有校准为概率，也不保证所有域外输入都会被拒绝。单一标签时只用距离阈值。允许用户标签名为 unknown，CLI 用 `known=0/1` 区分拒识。

同 ID 的再次教学替换原样本和标签，修订号增加；没有伪标签或自动把预测写回教学。分类更新不需要重新训练编码器，但这是有监督增量样本学习，不是自主概念发现、语言理解或符号推理。特征距离是相似性证据，不是语义证明。

`audio-save/load` 保存有版本头的特征、用户标签、来源 PCM 指纹及修订号；读取检查大小、数量、重复与有限特征值，失败时 CLI 旧模型保留。写入未做崩溃原子替换，指纹不是安全签名。音频样本不写入模型文件；名称标签仍可能含私人信息。原始 WAV 的采样率、帧数和 PCM 字节参与 FNV-1a 指纹；相同 PCM 的不同 WAV 包装会视为重复，保守拒绝可能的哈希碰撞。变速、增益、裁剪等近重复未识别，独立考试仍需由用户控制数据来源。

## 独立验证与资源成本

`audio-exam` 在打开考试清单前复制冻结学习器。清单 3..128 个带用户真值的 WAV，最多 64 KB；拒绝教学 PCM 重复及测试内重复；整个清单通过检查后才评分，不更新样本或阈值。报告冻结修订、cases/correct/unknown，仅描述这个测试集。文件路径相对于 CLI 工作目录，不相对于清单文件。

音频提取时间 O(8N)，内存 O(N)，N 最大 96000。最近邻 O(256×10)，固定维数；队列、来源表、文件读取有各自上限。算术命令 `limits/slice/cancel-next` 不控制音频命令；当前音频不支持协作取消或可续算切片。边界限制是工作量控制，不是硬实时、进程 RSS 或全局内存承诺。

自动化测试用独立相位、增益、采样率、时长的合成音调；覆盖纠错、重启、未知、歧义、重复考试、损坏格式和时钟误差。这不等于真实环境质量。`audio-benchmark` 测重复读取、提取与一次已教标签查询；数据热缓存、单样本、单线程，不能代表 256 样本端到端业务或设备功耗。

下一验收门槛：真实用户录音、不同设备／噪声／未知声音留出集、持续输入时的丢帧与延迟，手机／穿戴目标上的功耗实测。未取得这些证据前，P4 整体验收保留为进行中。

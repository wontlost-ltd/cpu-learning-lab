# 路线图

| 阶段 | 交付 | 验收 |
| --- | --- | --- |
| P0 已实现 | 原生 CLI、有限表达式归纳、保存加载、反例重学 | 当前功能测试通过；预测明确标为假设 |
| P1 已实现 | 保留有界多假设、分歧提问、独立评估任务 | 对 0/1 示例保留 x 与 x² 的歧义，主动询问新点；错误候选不能通过独立测试；报告仅声明测试集内的表现 |
| P2 已实现 | DSL AST/DAG、增量缓存、时间和内存预算、取消 | 报告质量、p50/p95、DAG 申请峰值及进程 RSS；取消／切片可续算，总上限停止须调整预算；回归检查旧行为 |
| P3 已实现 | 已学技能组合、抽象提取、版本回滚、回归回放 | 完成教学中未出现的组合任务；固定版本依赖；发布前回放其他活动技能；持久化与重启回归 |
| P4 进行中：连续输入已实现 | 有界观察流、显式时钟误差对齐、PCM16 WAV／连续帧、可选 PortAudio、窗口边界用户纠错、持久化与独立考试 | 合成音频闭环已验证；无预训练模型。连续输入和可选 Linux 适配器由 CI 验证；真实麦克风、目标设备延迟和功耗验收待完成 |
| P5 进行中：可靠事件与配对 TLS 已实现 | 持久设备事件、幂等文件同步、离线配对／鉴权／撤销和原生 TLS 补传；手机／穿戴及 ChronoSynth 适配待实现 | 软件测试验证跨重启、提交后断线、幂等、TLS 证书绑定、设备鉴权／撤销与来源限制；物理断电、安全审计、设备部署和执行评估驱动的学会事件待验收 |

不承诺任意领域专家或不受限制的自主成长。阶段以证据推进，不以模块名称或自我叙事宣告完成。

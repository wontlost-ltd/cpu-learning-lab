# 路线图

| 阶段 | 交付 | 验收 |
| --- | --- | --- |
| P0 已实现 | 原生 CLI、有限表达式归纳、保存加载、反例重学 | 当前功能测试通过；预测明确标为假设 |
| P1 下一阶段 | 保留有界多假设、分歧提问、独立评估任务 | 对 0/1 示例保留 x 与 x² 的歧义，主动询问新点；错误候选不能取得能力认证 |
| P2 | DSL AST/DAG、增量缓存、时间和内存预算、取消 | 固定 CPU 基准中报告质量、p50/p95 延迟与峰值内存；超预算可恢复，旧能力不退化 |
| P3 | 已学技能组合、抽象提取、版本回滚、巩固回放 | 完成教学中未出现的组合任务；学习前后冻结旧任务集对比 |
| P4 | 观察流、时间对齐、一个音频或视觉适配器 | 使用真实传感器反馈产生可验证局部改善；记录预训练先验与功耗 |
| P5 | 手机／穿戴采集及 ChronoSynth 适配 | 断连不丢已确认经验，恢复同步幂等；只有执行评估达标才输出学会事件 |

不承诺任意领域专家或不受限制的自主成长。阶段以证据推进，不以模块名称或自我叙事宣告完成。
